# iOS 捷徑（Shortcut）語音記帳設定教學

讓您在 iPhone 上對著 Siri 說「嘿 Siri，記帳」，就能用語音把消費送進「家庭財務戰情室」。本教學一步步帶您建立這個捷徑。

> 原理：iOS 捷徑透過「聽寫文字」把您說的話轉成文字，再用「取得 URL 內容」把文字 POST 到本專案的 `/api/voice-expense` API，後端用 Gemini（或內建規則）解析成結構化記帳資料後回傳，最後用通知顯示結果。

---

## 一、事前準備

1. 確認您的「家庭財務戰情室」已部署，且有一個可公開存取的網址，例如：
   - `https://你的網址/api/voice-expense`
2. iPhone 內建的「**捷徑**」App（iOS 13 以上皆內建，若被刪除可至 App Store 重新下載）。
3. 第一次執行「取得 URL 內容」時，iOS 會詢問是否允許連線到您的網域，請選「允許」。

---

## 二、API 規格

- **方法**：`POST`
- **網址**：`https://你的網址/api/voice-expense`
- **Headers**：`Content-Type: application/json`
- **Request Body（JSON）**：

```json
{ "text": "我中午吃便當花了 350" }
```

- **回傳（JSON）**：

```json
{
  "parsed": {
    "amount": 350,
    "category": "餐飲食品",
    "date": "2026-06-06",
    "note": "中午吃便當",
    "paid_for": "Both"
  },
  "source": "gemini",
  "original": "我中午吃便當花了 350"
}
```

### cURL 範例（可先在電腦上測試 API 是否正常）

```bash
curl -X POST "https://你的網址/api/voice-expense" \
  -H "Content-Type: application/json" \
  -d '{"text":"我今天加油花了 1200"}'
```

## 三、建立捷徑（逐步）

1. 開啟「**捷徑**」App → 右上角 **＋** 新增捷徑。
2. 點「**加入動作**」，依序加入下列動作：

### 動作 1：聽寫文字（Dictate Text）
- 搜尋「**聽寫文字**」並加入。
- 語言選擇「**國語（台灣）**」。
- 這一步會在執行時打開麥克風，把您說的話轉成文字。

### 動作 2：文字（Text）— 組成 JSON
- 搜尋「**文字**」並加入。
- 內容填入：
  ```
  {"text":"[聽寫文字]"}
  ```
  - 其中 `[聽寫文字]` 請點選變數選單，插入上一步「聽寫文字」的結果（不要自己打字，要用變數）。

### 動作 3：取得 URL 內容（Get Contents of URL）
- 搜尋「**取得 URL 內容**」並加入。
- **URL** 填：`https://你的網址/api/voice-expense`
- 展開「顯示更多」：
  - **方法（Method）**：`POST`
  - **要求內文（Request Body）**：選 **檔案（File）**，並把上一步的「文字」變數拖進來。
    （或選 JSON，欄位 `text` 對應聽寫文字變數）
  - **標頭（Headers）**：新增一個 `Content-Type` = `application/json`

### 動作 4：從輸入取得字典值（Get Dictionary Value）
- 加入「**取得字典值**」。
- 取得「**parsed**」這個鍵的值（這是解析後的記帳資料）。

### 動作 5：顯示通知（Show Notification）
- 加入「**顯示通知**」。
- 內容填入上一步的字典值，例如：
  ```
  已記帳：[parsed]
  ```
  - 這樣執行完會跳出通知，讓您確認金額、類別、日期是否正確。

3. 點右上角完成，並把捷徑命名為「**記帳**」。

---

## 四、加到 Siri（語音觸發）

1. 在捷徑的設定（點捷徑右上角的 **ⓘ** 或長按捷徑 → 詳細資訊）。
2. 找到「**加入 Siri**」或直接因為捷徑名稱是「記帳」，Siri 會自動支援。
3. 之後只要說：**「嘿 Siri，記帳」**，Siri 就會開始聽寫，您接著說出消費內容即可，例如：
   - 「中午吃便當花了 350」
   - 「今天加油 1200」
   - 「幫 CY 買咖啡 150」

---

## 五、加到主畫面（選用）

- 在捷徑詳細資訊中選「**加入主畫面**」，就能像 App 一樣一鍵啟動記帳。

---

## 六、分享給家人（iCloud 分享連結）

建立好捷徑後，可在捷徑上長按 → 「**分享**」→ 「**拷貝 iCloud 連結**」，
產生一個 `https://www.icloud.com/shortcuts/...` 連結傳給家人，
對方點開即可一鍵安裝同一個捷徑（安裝時記得把 URL 換成自己的網址）。

> 註：iCloud 分享連結需由您在自己的 iPhone 上實際建立捷徑後產生，無法由系統預先生成。
> 建議建立完成後把連結貼回此文件，方便家人取用：
>
> `iCloud 捷徑連結：（請貼上）`

---

## 七、常見問題

| 問題 | 解法 |
| --- | --- |
| 通知顯示空白或錯誤 | 先用上方 cURL 測試 API 是否正常回傳；確認網址結尾是 `/api/voice-expense` |
| Siri 聽不懂中文 | 在「聽寫文字」動作把語言設為「國語（台灣）」 |
| 連線被擋 | 第一次執行時 iOS 會問是否允許連到您的網域，請選「允許」 |
| 想直接寫入資料庫 | 目前 API 只回傳解析結果（不寫 DB）。接上 Supabase 後，可在後端擴充寫入邏輯 |
